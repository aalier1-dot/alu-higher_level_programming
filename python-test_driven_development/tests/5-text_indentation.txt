The ``5-text_indentation`` module
===================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic sentence with a period:

    >>> text_indentation("Hello. How are you? Fine: thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks.
    <BLANKLINE>

Text with no delimiter is printed as is:

    >>> text_indentation("Hello world")
    Hello world

Empty string prints nothing:

    >>> text_indentation("")

# Almost a Circle

A Python project implementing Base, Rectangle, and Square classes
with JSON and CSV serialization, as part of the ALU
Higher Level Programming curriculum.

## Files

- `models/base.py`: Base class (id management, JSON/CSV serialization)
- `models/rectangle.py`: Rectangle class, inherits from Base
- `models/square.py`: Square class, inherits from Rectangle
- `tests/`: unit tests for all classes

# python-input_output

This project covers file input/output in Python: reading from and writing to text files (UTF8), appending to files, working with JSON, pickling objects, and handling HTTP requests.

## Tasks

- `0-read_file.py`: reads a text file (UTF8) and prints it to stdout.
- `1-write_file.py`: writes a string to a text file (UTF8), creating or overwriting the file, and returns the number of characters written.
